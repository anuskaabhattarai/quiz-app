# quiz-app

## Description
This is a simple Quiz App built using HTML, CSS and JavaScript. It displays questions and tracks the user's score based on selected answers.

## Features
* Multiple choice questions
* Score tracking
* Dynamic question display
* Simple user interface

## Technologies Used
* HTML
* CSS
* JavaScript

## What I Learned
* Working with arrays and objects
* DOM manipulation
* Event handling
* Managing application state

## How to Run
1. Clone or download the repository
2. Open index.html in a browser

## Project Structure
* index.html
* style.css
* script.js
